## How to Activate Windows / Office / Extended Security Updates (ESU)?

The original project explains its methods and provides the current instructions. For the exact content shown in the original repository, use its official README:

### Method 1 — PowerShell ❤️

1. Visit the **[original MAS README](https://github.com/massgravel/Microsoft-Activation-Scripts#method-1---powershell-)**.
2. Review the instructions and security notes before running anything.
3. Follow the instructions from the original maintainer rather than relying on copied commands that may become outdated.

### Method 2 — Traditional (Windows Vista and later)

1. Open the **[original MAS README — Traditional method](https://github.com/massgravel/Microsoft-Activation-Scripts#method-2---traditional-windows-vista-and-later)**.
2. Find the maintained download links and instructions at that source.
3. Verify downloaded files and their source before execution.

---

> [!TIP]
> **Need help?** Use the **[official troubleshooting site](https://massgrave.dev/troubleshoot)** or the **[original project's issues](https://github.com/massgravel/Microsoft-Activation-Scripts/issues)**. Report issues with MAS itself to its maintainers, not to this reference page.

> [!NOTE]
> PowerShell commands that download and immediately execute code can create security risks. Inspect what you run, verify the domain and maintainers, and do not execute URLs copied from untrusted videos, chats, or lookalike websites.
